# 台語小遊戲

兩個台語小遊戲合成一個網站，用下方分頁切換，手機瀏覽器就能玩。

遊玩網址：https://hankju.github.io/taigi-yeshi-words/

| 分頁 | 資料夾 | 內容 |
| --- | --- | --- |
| 🏮 踅夜市單詞 | `yeshi/` | 台語課第一課〈來去踅夜市〉單詞練習：台羅拼音、台羅＋詞義、台文填空 |
| 🧧 過年好話 | `newyear/` | 過年吉祥話押韻：好話飄飄、翻紅包、搶答放炮 |

- 直接連到某個分頁：`#yeshi`、`#newyear`（例：`…/taigi-yeshi-words/#newyear`）
- 會記住上次停在哪個分頁；切換分頁時另一邊的遊戲進度不會不見
- 每個遊戲仍是獨立的單一 HTML，可以單獨打開 `yeshi/`、`newyear/`

## 資料來源與授權

〈來去踅夜市〉補充詞的台羅、釋義、例句，以及 `yeshi/audio/` 資料夾內的錄音，取自教育部《臺灣台語常用詞辭典》（https://sutian.moe.edu.tw/），依 CC BY-ND 3.0 TW 授權使用，錄音未經修改。
